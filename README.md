# 日常工作工具箱

一个公开部署的、无需登录的静态工具箱。

当前工具：

- **化学品安全信息**：通过 Wikidata 名称映射 + PubChem 查询安全摘要与官方数据库链接
- **Markdown**：左侧编辑、右侧实时预览，草稿自动保存在本机（参考 [markdown.com.cn/editor](https://markdown.com.cn/editor/)）
- **文本处理**：统计、清理、去多余回车、排序与去重（本地运行）
- **文本对比**：逐行查看新增、删除与未变化内容（本地运行）
- **网址快捷键**：在首页保存常用网址，添加后生成图标快捷入口（本地运行）

线上地址：https://summeredge.github.io/Tools/

## 本地运行

```bash
npm install
npm run dev
```
